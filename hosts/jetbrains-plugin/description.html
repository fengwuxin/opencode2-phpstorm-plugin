OpenCode UX+ JetBrains 插件（fengwuxin）

面向 opencode v2 的 JetBrains 插件。

  • 为当前项目运行本机安装的 opencode serve
  • 把聊天界面嵌入 IDE 工具窗口，并限定在当前项目
  • 拖拽文件即可添加到提示词上下文
  • 通过菜单或快捷键把当前文件 / 选中行添加到上下文
  • 点击消息里的文件路径可在编辑器中打开

环境要求：系统已安装 opencode v2.0.0 或更高版本。插件不内置后端， 可执行文件会从 IDE 设置、常见安装位置（homebrew、nvm、bun 等）或 shell 的 PATH 中解析。
