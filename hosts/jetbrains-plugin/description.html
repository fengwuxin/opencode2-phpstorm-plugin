OpenCode UX+ JetBrains Plugin (fengwuxin)

OpenCode JetBrains plugin for opencode v2.

  • Runs the locally installed opencode serve for the current project
  • Embeds the chat UI in the IDE tool window, scoped to the current project
  • Drag and drop files to add them to the prompt
  • Add the current file / selected line ranges to context via command or shortcut
  • Clicking a file path in a message opens it in the editor

Requirements: opencode v2.0.0 or newer installed on the system. The plugin does not bundle the backend. The executable is resolved from the IDE settings, well known install locations (homebrew, nvm, bun, ...) or the shell PATH.
