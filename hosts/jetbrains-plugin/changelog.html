OpenCode GUI Only 更新日志

26.9.2910

  • 输入框顶部内边距恢复原样（去掉上一步临时加的 pt-8）；与结束分割线的间距仍由滚动区内的占位元素保证，约 39px

26.9.2909

  • 修复结束分割线与输入框间距不生效：滚动容器会忽略最后一个元素的底部 margin（CSS 行为），改用「占位元素高度 + 输入区上内边距」，实测间距 14px → 71px

26.9.2908

  • 结束分割线下边距再加大：16px → 48px（加上滚动区底部内边距，实际与输入框间距约 60px）

26.9.2907

  • 结束分割线文案改为「本轮已结束」（英文 Turn finished）
  • 结束分割线下方留白加大（与输入框之间更宽松）

26.9.2906

  • 修复会话标题不显示/不刷新：opencode v2 的 session.renamed 事件用 sessionID 标识会话，前端却按 id 匹配，导致标题更新被丢弃（现在事件会补上 id，并且部分更新改为合并，不会覆盖已有字段）
  • 同类修复：会话删除事件也按 sessionID 读取，其他客户端删除的会话现在能同步移除

26.9.2905

  • 消息列表底部新增「本轮已完成」结束分割线（虚线 + 对勾 + 文字），回答结束一眼可见
  • 「生成中」指示器改为由服务端会话状态驱动，并在会话转入空闲时同步清理本地状态——修复"生成中切到别的会话、回来后一直显示生成中"的问题
  • 执行中隐藏结束标记，执行结束自动显示

26.9.2904

  • 会话列表严格按最后活跃时间倒序（收藏、当前会话都不再参与排序）
  • 正在执行的会话显示 loading 状态（转圈 +「运行中」），执行结束自动恢复为时间显示
  • 修复 session.idle 事件未清理运行状态的问题（否则 loading 会一直转）

26.9.2903

  • 输入框问候语跟随界面语言：中文显示「你好，{用户名}」，英文显示「Hello {用户名}」（用户名未配置时中文为「主人」、英文为「owner」）
  • i18n 的 t() 支持 {name} 形式的参数插值

26.9.2902

  • 中文输入法兼容性：所有键盘处理（会话搜索、快捷键、Esc 关闭）在输入法组合状态下不再拦截按键，方向键/回车/空格交还给输入法候选框
  • 启动时在 IDE 日志中记录 JCEF 离屏渲染（OSR）状态：ide.browser.jcef.osr.enabled 为 true 时，内嵌浏览器可能出现中文输入法无法输入的问题，可到 Registry 里关掉该开关并重启 IDE

26.9.2901

  • 会话列表：改为按“最近活跃时间”排序，当前会话和最近继续过的会话排在最前（原来按创建时间排）
  • 会话列表：时间显示改为最后活跃时间；移除分享按钮（opencode v2 没有分享接口）
  • 会话列表：新增收藏按钮（星标），收藏状态保存在插件 kv 中

26.9.2802

  • 为 JetBrains 官方插件市场发布做准备：去掉 until-build 上限，插件在比构建平台更新的 IDE（如 2026.2+）上也能安装
  • 新增 publishPlugin 配置（读取 PUBLISH_TOKEN 环境变量），后续版本可一键发布到插件市场

26.9.2801

  • 修复回答提问后卡住不动：回复表单时按 v2 的字段 key 传值（原来发的是 {answer:{value:[...]}}，服务端报 Unknown form field: value，表单一直 pending 导致模型一直等待）
  • 选项标签自动映射回字段的 value，多选字段传数组，数字/布尔字段按类型转换，自定义输入原样提交
  • 回答失败时弹提示（原来静默失败，看着像卡死）

26.9.2518

  • 插件更名 OpenCode GUI Only，作者 fengwuxin；插件 ID 变更，旧版需先卸载再安装
  • 新图标：超椭圆外轮廓 + opencode 原有图形；工具窗口为实心 opencode 剪影（浅色/深色主题两套）
  • 界面中英文可切换（默认中文），深色主题下的控件、浮层与下拉配色全面适配
  • 设置：默认模型 / 标题模型改为下拉选择；Provider 可勾选启用；快照默认开启
  • 模型列表：默认展示启用 Provider 的全部模型，可单独隐藏；不再与桌面客户端同步
  • 输入框：Enter 发送、Cmd/Ctrl+Enter 换行，默认两行高度，问候语显示配置的用户名
  • 稳定性：修复思考深度偶发不可用、标题模型保存后不回显、模型列表加载中断等问题

  • 自动处理 HTTP Basic 认证；新增 opencode 可执行文件路径设置；不再内置后端二进制
  • 早期修复：设置保存与字段对齐 v2、推理变体选择、会话列表按项目过滤、粘贴图片、插件图标
